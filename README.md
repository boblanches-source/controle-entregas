# Controle de Entregas em Tempo Real

## Backend
```bash
npm install
npx knex migrate:latest
npm start
```

## Frontends
- `public/balcao/index.html` + `public/balcao/app.js`
- `public/motoboy/index.html` + `public/motoboy/app.js`

Ajuste `window.API_BASE` em cada `index.html` para apontar para sua API hospedada.
